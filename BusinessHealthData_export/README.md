# Local business and property exports

Keep business-license workbooks and property source exports in this directory at their original relative paths. These datasets are intentionally excluded from Git; existing local copies remain available for the analyses that use them.

This README preserves the directory in the repository. Obtain the required datasets separately from the project data owner before running an analysis that depends on them.

The current Study 1 offline pipeline does not depend on these exports. Its excluded input requirements are documented in [PUBLIC_REPOSITORY.md](../study_1/PUBLIC_REPOSITORY.md).
