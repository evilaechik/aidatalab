# Source registry

| Dataset | Publisher | URL | Downloaded scope |
| --- | --- | --- | --- |
| QCEW area slices | U.S. Bureau of Labor Statistics | https://www.bls.gov/cew/additional-resources/open-data/csv-data-slices.htm | Q4 2023-2025 for 10 core metro counties, all published industries |
| LODES | U.S. Census Bureau LEHD | https://lehd.ces.census.gov/data/lodes/ | Georgia WAC, RAC, and OD files for 2023 |
| Place boundaries | U.S. Census Bureau | https://www.census.gov/geographies/mapping-files/time-series/geo/cartographic-boundary.html | Georgia 2024 place boundaries |
| MARTA GTFS | MARTA | https://itsmarta.com/app-developer-resources.aspx | Current static transit feed |

Use the source documentation before interpreting a field. QCEW values can be suppressed for disclosure protection. LODES values are tabulated/model-based and should not be interpreted as an exact employee count at an individual office.
